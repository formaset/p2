# Система интеллектуального оперативного планирования

## Аннотация
Программа представляет собой многоуровневую систему интеллектуального оперативного планирования и оптимизации показателей функционирования производственных процессов промышленного предприятия. Архитектура реализована в виде модульного приложения на Python с использованием объектно-ориентированного подхода и включает следующие основные компоненты:

- **Модели данных** описывают ресурсы, задачи, операции и заказы, поддерживая расчёт стоимости, рисков и ограничений по мощности.
- **Хранилище производственных данных** агрегирует справочную информацию, календарные ограничения и шаблоны технологических карт для разных типов продукции.
- **Эвристический оптимизатор** формирует расписание операций, используя метрики стоимости, риска и загрузки ресурсов, а также обеспечивает корректировку плана при изменении условий.
- **Имитационная модель** позволяет рассчитать ключевые KPI (себестоимость, время цикла, уровень риска) на основе сформированного плана и сценарных допущений.
- **Модуль отчётности** формирует аналитические отчёты о выполнении плана, загрузке ресурсов и прогнозируемых показателях эффективности.
- **CLI-интерфейс** предоставляет удобные сценарии для запуска планирования, выбора входных данных и сохранения отчётов.

Система предназначена для предприятий, стремящихся повысить устойчивость и эффективность производственных процессов. Она обеспечивает гибкую настройку стратегий планирования, поддержку современных методов оценки риска и оперативную адаптацию к изменяющимся условиям, предоставляя инженерам и аналитикам целостный инструмент управления производством.
